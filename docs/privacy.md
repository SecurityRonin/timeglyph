# Privacy Policy

**Effective date:** 2026-06-28
**Product:** timeglyph CLI
**Operator:** Security Ronin Ltd

---

## What timeglyph collects

Nothing. `timeglyph` is a local command-line tool. It has no server, no backend,
and makes **no network connections of any kind**. It does not transmit data to
Security Ronin or any third party.

## Input data

`timeglyph` reads the timestamp values and byte sequences you pass on the command
line, decodes them in memory, and prints the result. It does not read, store, or
upload any file content, and it writes nothing to disk.

## Telemetry

`timeglyph` has no telemetry, no crash reporting, no analytics, and no update
checks. It never phones home.

## Open source

`timeglyph` is fully open source under the Apache-2.0 licence. You can audit every
line — including the (empty) set of network calls — at
[github.com/SecurityRonin/timeglyph](https://github.com/SecurityRonin/timeglyph).

## Changes

If this policy changes materially, the effective date above will be updated and a
note will appear in the release changelog.
